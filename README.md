# server_notification


## Требования к установке

Для работы с асимметричным шифрованием и криптографией в проекте используется библиотека **QCA (Qt Cryptographic Architecture)**.

### Установка зависимостей (Linux, Ubuntu/Debian)

Перед сборкой проекта установите необходимые пакеты:

```sh
sudo apt install libqca-qt5-2 libqca-qt5-2-dev
```
